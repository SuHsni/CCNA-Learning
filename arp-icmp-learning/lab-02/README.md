# Inter-Network Communication Using a Router Gateway

## Network Topology

In this scenario, a network topology was designed and simulated using
Cisco Packet Tracer. The topology consists of one router, one multilayer
switch, multiple access switches, and several end devices.

The router has two interfaces, each connected to a different IP network:

- G0/0/0 → 172.16.16.1/24
- G0/0/1 → 172.16.17.1/24

The first router interface is connected to the Multilayer Switch.
The Multilayer Switch then connects to two Access Switches, with each
Access Switch connected to a PC and a Laptop.

The second router interface is connected to another switch, which has
two end devices connected to it.

## IP Networks

| Network        | Gateway     | Example Host         |
| -------------- | ----------- | -------------------- |
| 172.16.16.0/24 | 172.16.16.1 | PC0: 172.16.16.10    |
| 172.16.17.0/24 | 172.16.17.1 | Laptop: 172.16.17.11 |

## Connectivity Test

To verify inter-network communication, an ICMP ping was sent from:

**PC0**
`172.16.16.10`

to:

**Destination Laptop**
`172.16.17.11`

Since these two devices belong to different IP networks, PC0 cannot
communicate directly with the destination at Layer 2. Instead, it sends
the packet to its Default Gateway, `172.16.16.1`.

## Packet Flow

The communication process can be summarized as follows:

1. PC0 needs to communicate with `172.16.17.11`.
2. PC0 determines that the destination belongs to a different subnet.
3. PC0 uses ARP to discover the MAC address of its Default Gateway,
   `172.16.16.1`.
4. The ICMP Echo Request is sent from PC0 to the router through the
   Multilayer Switch.
5. The router examines the destination IP address and determines that
   `172.16.17.0/24` is reachable through its second interface,
   `172.16.17.1`.
6. The router uses ARP on the `172.16.17.0/24` network to discover the
   MAC address of the destination Laptop.
7. The router forwards the ICMP packet through its G0/0/1 interface,
   across the connected switch, to the destination Laptop.
8. The Laptop sends an ICMP Echo Reply back through its Default Gateway.
9. The router receives the reply and forwards it toward
   `172.16.16.0/24`, eventually reaching PC0.

## ARP and ICMP Analysis

The packet exchange was analyzed using the **Simulation Mode** in
Cisco Packet Tracer.

Only the following protocols were enabled in the simulation filters:

- **ARP** – Used to resolve IP addresses to MAC addresses on the local
  network.
- **ICMP** – Used to observe the Echo Request and Echo Reply packets
  generated by the `ping` command.

The simulation demonstrates that the Router acts as the Layer 3 gateway
between the two different IP networks.

Therefore, the communication path is:

PC0 → Multilayer Switch → Router → Switch → Destination Laptop

and the return traffic follows the reverse path.
